🎲 Ludo

A modern web-based Ludo game featuring Single Player AI, local Pass & Play, and real-time online multiplayer gameplay.

live demo web - https://ludoedition.onrender.com

✨ Features

- 🤖 AI Mode — Play Ludo against AI opponents.
- 👥 Pass & Play — Play with friends on the same device.
- 🌐 Online Multiplayer — Play with other players remotely.
- 🏠 Create Room — Create a private multiplayer game room.
- 🔑 Random Room Code — Generate a unique code for each multiplayer session.
- 🔗 Join Room — Join a game using a room code.
- ⚡ Real-Time Gameplay — Multiplayer moves are synchronized in real time.
- 🎲 Dice System — Interactive dice-based gameplay.
- 🏠 Token Movement — Move tokens according to dice results.
- 🏆 Winning System — Detects the player who successfully completes the game.
- 🔄 Play Again — Start a new match after completing a game.
- 📱 Responsive Design — Designed for desktop and mobile devices.

🎮 Game Modes

🤖 AI Mode

Play Ludo against computer-controlled opponents.

The AI handles its turns automatically, allowing you to play a single-player match without requiring another person.

👥 Pass & Play

Play with friends on the same device.

Players take turns using the same screen:

Player 1 → Player 2 → Player 3 → Player 4

The number of participating players depends on the available game configuration.

🏠 Create a Room

1. Select Online Multiplayer.
2. Create a new room.
3. A random room code is generated.
4. Share the code with other players.
5. Players enter the code to join.
6. Start the Ludo match.

🔗 Join a Room

1. Select Online Multiplayer.
2. Enter the room code.
3. Join the game.
4. Wait for the other players.
5. Start playing.

🎲 How to Play

1. Roll the dice.
2. Select an eligible token.
3. Move the token according to the dice result.
4. Try to move all your tokens to the home area.
5. The player who completes the required objective first wins the match.

⚠️ Notes

- Online multiplayer depends on the underlying real-time communication infrastructure and network conditions.
- Peer-to-peer connections may be affected by NAT or firewall restrictions.
- Online rooms are intended for temporary game sessions.
- AI and Pass & Play modes do not require an online multiplayer room.
